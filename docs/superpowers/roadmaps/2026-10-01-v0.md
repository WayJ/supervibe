# plugin v0.1.0 published

Epic E1 is supervibe's self-hosting epic: it dogfoods the plugin's own artifact
model to carry its own v0 implementation. The sprint below started before this
epic doc existed (the spec/plan pair predate the epic scaffold) — the stub row
records the as-found state, per the ledger rule that pre-start states live only
here and started states live in the sprint doc's frontmatter.

## Deliverables

| deliverable | note |
|---|---|
| Five skills (roadmap, start, accept, merge, sync), bilingual EN/zh | trigger-condition descriptions per the SDO rule; each `SKILL.md` mirrored by `SKILL.zh.md` |
| Six templates (epic, sprint, acceptance-record, handover-clause, debt-entry, agents-sections) | dated-directory artifact model; exact `<!-- placeholder: ... -->` syntax |
| `tests/check-artifacts.mjs` — zero-dep CI check | bilingual pairing, template completeness, assembly dry-run |
| Self-hosted marketplace (`.claude-plugin/`) | plugin.json + marketplace.json, source `./` |
| Bilingual README + CHANGELOG | install via `/plugin marketplace add WayJ/supervibe` |

## Definition of Done

- [ ] All five skills pass `claude plugin validate . --strict`
- [ ] `node tests/check-artifacts.mjs` green — templates complete, pairs intact
- [ ] Every skill ships both `SKILL.md` and `SKILL.zh.md`
- [ ] README bilingual (EN main + zh section), install path documented
- [ ] Plugin installs via `claude --plugin-dir .` smoke check
